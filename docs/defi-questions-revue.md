## Question Totem 🐾

**Poids :** ×2 points (affiché "Question bonus ×2 🐾")
**Scoring :** exact = 2 points, faux = 0 point (pas de "presque")
**Format :** 4 options (1 vrai animal + 3 distracteurs aléatoires)
**Question :** D'après toi, c'est quoi le totem de {prenom} ?

---

## Scoring

| Résultat | Points |
|----------|--------|
| Bonne (exact match) | 1 × poids |
| Presque (bande adjacente, 3 options) | 0.5 × poids |
| Mauvaise (opposé ou 2 options) | 0 |
| Totem bonne | 2 |
| Totem mauvaise | 0 |
| **Score final** | round(totalPoints / maxPoints × 100) % |

## Bandes population (tertiles)

**Statut :** Netlify Function `defi-compute-bands` créée.

```
POST /.netlify/functions/defi-compute-bands
Authorization: Bearer <token>
Body: {}                          ← dry run (par défaut)
Body: { "dryRun": false }         ← écriture dans config/defiBands
```

Les dimensions avec n < 50 conservent les plages cliniques.
